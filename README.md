# Cafeteria Aroma

Site desenvolvido para uma cafeteria fictícia, com uma proposta clean, aconchegante e moderna.

O projeto apresenta o cardápio da cafeteria, informações sobre o estabelecimento e uma área de contato, utilizando uma interface simples e responsiva.

## Sobre o projeto

A Cafeteria Aroma foi desenvolvida com o objetivo de criar uma experiência visual agradável para apresentar uma cafeteria e seus produtos.

O site possui:

* Página inicial
* Apresentação da cafeteria
* Cardápio de produtos
* Filtro por categoria
* Informações de contato
* Layout responsivo
* Imagens dos produtos
* Design clean e moderno

## Tecnologias utilizadas

* React
* Vite
* JavaScript
* HTML5
* CSS3

##  Como executar o projeto

Primeiro, clone o repositório:

```bash
git clone https://github.com/gabrielacarolline/cafeteria-aroma.git
```

Entre na pasta:

```bash
cd cafeteria-aroma
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npm run dev
```

Depois, abra no navegador o endereço informado pelo Vite.

##  Cardápio

O site apresenta diferentes opções de:

* Cafés
* Bebidas
* Doces

O cardápio possui filtros para facilitar a visualização dos produtos.

##  Responsividade

O layout foi desenvolvido para funcionar em diferentes tamanhos de tela, incluindo computadores, tablets e celulares.
